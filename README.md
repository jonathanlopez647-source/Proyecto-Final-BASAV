# 🚛 Proyecto BASAV - Transportes Luchito EIRL
Solución de Inteligencia de Negocios y Big Data para el control automatizado de "Horas Motor" y telemetría de flota de volquetes.

## 📁 Estructura del Repositorio
* `/BI_SQL_Server/`: Scripts DDL de la BD Transaccional, Data Mart (Estrella) y T-SQL ETL.
* `/BigData_Spark/`: Scripts Python generadores de telemetría y Notebooks PySpark para procesamiento distribuido.
* `/PowerBI/`: Dashboard `.pbix` conectado en modo importación al Data Mart.
* `/Docs/`: Documentación, diagramas de arquitectura e informe final.
